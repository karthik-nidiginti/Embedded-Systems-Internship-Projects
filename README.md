##  Projects Overview

### Project 1 – Adaptive Battery Intelligence
An intelligent battery monitoring system that dynamically adapts to usage patterns, tracks charge levels, and optimizes power consumption in real time.

🔗 **Simulation:** [View on Wokwi](https://wokwi.com/projects/465376987727778817)


### Project 2 – Event-Driven Safety Protocol
An event-driven embedded system designed to detect safety-critical conditions and trigger appropriate responses with minimal latency.

🔗 **Simulation:** [View on Wokwi](https://wokwi.com/projects/465375575917488129)


### Project 3 – Intelligent Embedded Control
A smart embedded controller implementing sensor fusion and decision logic for automated real-world control applications.

🔗 **Simulation:** [View on Wokwi](https://wokwi.com/projects/465378963580763137)


### Project 4 – Fault-Tolerant Embedded System
A robust embedded design with built-in fault detection and recovery mechanisms to ensure system reliability under failure conditions.

🔗 **Simulation:** [View on Wokwi](https://wokwi.com/projects/465731333637156865)


### Project 5 – Intelligent Cloud Telemetry
An IoT-enabled embedded system that collects sensor data and transmits it to the cloud for real-time monitoring and analytics.

🔗 **Simulation:** [View on Wokwi](https://wokwi.com/projects/465858709519483905)


### Project 6 – Executive Battery Intelligence
An advanced battery management system providing high-level insights, diagnostics, and predictive analytics for executive-level reporting.

🔗 **Simulation:** [View on Wokwi](https://wokwi.com/projects/465907213063795713)
