# Project-4-Fault-Tolerant-Embedded-Runtime-System

A fault-tolerant embedded runtime subsystem capable of detecting and handling hardware/software failures autonomously. The system supports fault isolation, runtime monitoring, state transitions, recovery mechanisms, and fault logging.

## Features

- Sensor disconnection detection
- Invalid sensor value detection
- Frozen ADC detection
- Relay mismatch detection
- Runtime state management:
  - NORMAL
  - DEGRADED
  - FAILSAFE
  - SHUTDOWN
- Timestamped fault logging
- Automatic recovery handling
- Modular embedded architecture

## Hardware

- ESP32-S3
- Potentiometers (Sensor Simulation)
- Relay Output
- LEDs (Status Indicators)
- Buzzer (Optional)
